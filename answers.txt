Part - 1
Q1.(d) 

-Very Short Texts: Flesch–Kincaid uses average sentence length and syllable count. 
                    For example in a small title/tweet , just a single short sentence or a one long word will throw these averages off. 
                    The score then does not show real reading difficulty.
        
-Specialized language: There are languages which includes names,slang,technical terms, dialogue which does not follow normal English patterns.
                       The syllable counts and sentence structure which it knows is not there so the grade level can be too high or too low.

Q2.(f)

- I have build a spaCy-based tokenizer and it follows the following steps:

1. Contraction Expansion: - It uses the contractions library but ensuring vocabulary is consistent. For exampls here certain words such 
                            as can't gets expanded to cannot.

2. SpaCy Processing:- It processes the expanded text using spaCy, after which it tokenizes,llemmatizes and identifies named entities.

3. Token Filtering:
        - Punctuation Removal.
        - Number Filtering.
        - Stopword Removal.
        - Alphabetic Check.

4. Lemmatization:- It will convert the token to its original form.

5. Named Entity Extraction:- All the named entities such as organization, people etc will be extracted and will be added to the features.


Performance:

- The best model acheives a macro F1 score of 0.7134, which is higher than the previous models in which Random Forest make 0.4553
  and SVM made 0.594 respectively.

- Advance preprocessing and feature extraction has performed very well.

- The model performs really well for larger classes.

- It Provides a roboust feature and has strong classification performance.

- The downside is it takes longer preprocessing time ,but the trade off is worth the improved accuracy rate.
